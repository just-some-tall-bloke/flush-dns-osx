# flush-dns-osx

Shell script to flush the DNS cache for macOS

## Usage

    flush-dns

## Installation

    sudo make install

Or manually:

    sudo cp ./flush-dns.sh /usr/local/bin/flush-dns
    sudo chmod 0755 /usr/local/bin/flush-dns

To uninstall:

    sudo make uninstall

Or:

    sudo rm /usr/local/bin/flush-dns
